# Student Performance Analysis 📊

## About the Project
This project focuses on analyzing students' academic performance using Python, Pandas, and Matplotlib. It explores factors such as study time, absences, previous grades, and gender to understand patterns in students' final grades.

## Objectives
- Calculate the average final marks of students.
- Calculate the percentage of students who passed.
- Analyze the relationship between study time and academic performance.
- Explore the impact of absences on final grades.
- Compare average academic performance by gender.
- Visualize student performance through different graphs.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The project uses the **Student Performance Dataset** from the UCI Machine Learning Repository.

## Analysis Performed
- Data exploration and statistical summary.
- Missing value checking.
- Average final grade calculation.
- Pass percentage calculation.
- Study time vs. final grade analysis.
- Absences vs. final grade analysis.
- Distribution of final grades.
- Correlation analysis between student variables.
- Average final grade comparison by gender.

## Visualizations
The project includes:
- Bar Chart
- Scatter Plot
- Histogram
- Correlation Heatmap
- Gender-wise Performance Chart

## Project File
`Student_Performance_Analysis.ipynb`

## Conclusion
This project uses data analysis and visualization techniques to explore student academic performance and identify patterns between different student-related factors and final grades.
